# BanoQabil Grounded RAG Assistant

Fact-grounded Retrieval-Augmented Generation (RAG) assistant for the **BanoQabil** program built with **Pinecone** (`banoqabil-web`, 328 vectors) and **Google GenAI** with model fallback support, anti-hallucination and out-of-scope refusal guards, verified source citations, and a green-and-white multilingual UI with session exit and re-open controls.
